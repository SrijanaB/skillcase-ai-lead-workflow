How priority is scored

Kept rule-based and visible on purpose — a salesperson should be able to see exactly why a lead outranks another, not trust a black-box number.

Score = (German level × 2) + min(experience years, 5) + source bonus + urgency bonus − (objection base × severity multiplier)
  • German proficiency: B2 = +6 points, B1 = +4 points, A2 = +2 points, A1 / None = +0 points.
  • Experience: +1 point per year of relevant experience, capped at 5 points maximum.
  • Source bonus: Referral +1 point, WhatsApp +0.5 points.
  • AI-derived urgency: High +2 points (requesting call/immediate timeline), Medium +1 point (interested without timeline), Low +0 points (early exploration).
  • Objection category & severity penalty: Objection base × severity multiplier.
    • Base penalties: Price −2.0, Qualification −1.5, Eligibility −1.5, Confidence −1.0, Timeline −0.5, None 0.
    • Severity multipliers: Strong ×1.5, Moderate ×1.0, Mild ×0.5, None ×0 (defaults to Moderate if severity is missing or invalid for a stated objection).
  • Priority bands: High (≥ 8) · Medium (4–7.9) · Low (< 4). Leads classified as not relevant are excluded from scoring.
  • Quality control separation: Classification confidence is intentionally excluded from priority score calculations and is reserved strictly for QC review routing (flagging confidence < 0.6 for human review).
Classification, enrichment and outreach drafting are generated by Gemini at run time, through this app's own server — nothing here is pre-written. Rule-based steps (cleaning, deduplication, priority scoring, contradiction checks) run identically every time.
